# MOMENTARA — Situs Publik

Situs informasi dan pemesanan awal MOMENTARA, terpisah dari aplikasi privat MOMENTARA di Muse.

Halaman: Beranda (/), Cara Kerja, Fitur, Demo, Harga, FAQ, Kontak, Privasi, Syarat, Penghapusan Data.

Harga adalah harga awal pengujian. Pembayaran produksi dikonfirmasi admin. Privasi dan Syarat adalah draf untuk dikoreksi admin sebelum rilis produksi.

Deploy: situs statis, Vercel dengan cleanUrls true. Domain sementara yang dipakai di robots/sitemap adalah momentara-public.vercel.app dan harus disesuaikan bila nama proyek Vercel berbeda.
